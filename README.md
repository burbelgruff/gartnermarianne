# gartnermarianne.no

Statisk nettside for Marianne Holt, gartner på Øvre Romerike. Ingen byggesteg: `index.html`, `style.css` og `images/` blir servert som de er.

## Lokalt

```
npx serve .
```

eller åpne `index.html` direkte i nettleseren.

## Publisering (Cloudflare Pages)

- Koble repoet til Cloudflare Pages
- Build command: (tom)
- Build output directory: `/`
- Push til `main` publiserer automatisk

Se `MIGRERING.md` for flytting av domenet fra gammel WordPress-host.
